# LeadClear Systems — Vercel-ready website

This is a responsive, multi-page static website for LeadClear Systems. It uses plain HTML, CSS and JavaScript, so no build command or framework is required.

## Pages included
- Home (`index.html`)
- Services (`services.html`)
- Systems Audit (`systems-audit.html`)
- Project Management (`project-management.html`)
- SaaS Implementation (`saas-implementation.html`)
- SOP & Workflow Systems (`sop-workflow-systems.html`)
- Talent Network (`talent-network.html`)
- Academy — Coming Soon (`academy.html`)
- Products (`products.html`)
- About (`about.html`)
- Contact (`contact.html`)

## Deploy to Vercel
1. Download and unzip this folder.
2. Create a new GitHub repository, for example `leadclear-systems-website`.
3. Upload all files and commit them to the repository.
4. In Vercel, choose **Add New → Project**, import the GitHub repository and deploy.
5. Framework preset: **Other**. Build command: leave blank. Output directory: leave blank or use `.` if prompted.
6. Vercel will provide a preview URL. Test all pages and links before connecting a custom domain.

## Before launch
- Review the text and confirm that every service description matches the work you want to offer.
- The contact form opens a pre-filled email using `mailto:`. It does not store submissions. For a true web form, connect a form service or backend.
- Images currently use remote Unsplash image URLs. Replace these with approved brand images if preferred.
- The LC monogram is a temporary text-based mark. Replace it with the official LeadClear Systems logo file when ready.
- Update social links, legal pages and any final contact details as needed.
- The Academy waitlist currently routes to the Contact page. Connect a dedicated registration form when one is ready.
